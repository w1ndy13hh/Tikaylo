# Тикайло

Офлайн-кликер для Android: тыкаешь по котику, покупаешь улучшения, копишь тикоины.

Вся игра — один файл `app/src/main/assets/index.html` (HTML + CSS + JS, без внешних
ресурсов и интернета). Приложение — тонкая WebView-обёртка вокруг него.

## Что внутри игры

- 50 улучшений с разными механиками: плоские бонусы, ×2/×3/×5/×10/×20 к тыку,
  пассиву, криту и силе крита, составные бонусы «за каждый апгрейд»
- 100 достижений, у каждого — награда (бонусы к характеристикам), 15 самых сложных
  дают тикоины
- Лавка тикоинов: 15 усиленных улучшений за тикоины (+1 тикоин каждые 2:30, только онлайн)
- Криты, двойные тыки, офлайн-доход за обычные коины
- Свой звук на WebAudio (без файлов), тёмная тема, стеклянный UI
- Прогресс сохраняется локально (localStorage)

## Сборка

### Android Studio

Открыть папку проекта, дождаться синхронизации Gradle, Run ▶.

### Командная строка

```sh
gradle assembleDebug
# apk: app/build/outputs/apk/debug/app-debug.apk
```

Нужна JDK 17 и Android SDK (platform 34, build-tools 34).

## Структура

```
app/src/main/assets/index.html              — сама игра
app/src/main/java/com/tikailo/app/MainActivity.java — WebView-обёртка
app/src/main/AndroidManifest.xml            — манифест (package com.tikailo.app)
app/src/main/res/drawable/ic_launcher.xml   — иконка
app/src/main/res/values/strings.xml         — название приложения
```

## Требования

Android 7.0 (API 24) и выше. Интернет не нужен.
